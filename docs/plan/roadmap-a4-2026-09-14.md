# Plan rozwojowy — układ A4 w materiałach logopedycznych (2026-09-14)

**Kontekst:** 84 szablony (72×3p +9×2p +3×1p), `design-system.ts` 744px budget, `modular-a4-pipeline.md` 6 modułów, research `a4-layout-children-therapy-2026-09-14.md` (ISO 216, WCAG, worksheet design). Cel: jednolity, produkcyjny standard druku A4 300 dpi, 2-5 stron per karta, gotowy do laminowania i ksero B&W.

**Design read:** print A4 dla 4-7 lat, playful editorial, dodle pastel+vivid, VARIANCE 7 / MOTION 3 / DENSITY 4 — bez AI slop, 1 accent per karta, shape lock 22/16/28.

---

## 1. Zasady nadrzędne (z research)

- **Fizyczny A4:** 210×297 mm, 1:√2, 2480×3508 @300 dpi, margines safe 12 mm, bleed 3 mm gdy tło do krawędzi, gutter > outer.
- **Przestrzeń:** 40-60% bieli, odpowiedź dopasowana (linia na zdanie, box na diagram), ≤8 słów bazowych (5 chunków WM), chunking 3-6.
- **Typografia:** Andika/Baloo2/Sassoon infant single-story, 14-18 pt print (≈11-12 px PDF), LH 1.6, tracking 0.3px, left-align, nie justowanie/caps/italic.
- **Kolor:** WCAG AA 4.5:1 (3:1 large), nie tylko kolorem (kształt+tekst P/S/K), test B&W, CMYK proof (neon poza gamutem).
- **Kolejność:** header imię/data → tytuł→instrukcja bold ≤20 słów → zadania góra→dół → biel między sekcjami.

## 3. Metryki sukcesu (per karta, per build)

- **A4:** 210×297, 300 dpi, 12 mm safe, 3 mm bleed, `pages` 2-5 (ćwiczeniowe) / 1 (nagrody) — `pages.json` Counter
- **Biel:** 40-60% (dziś 22% → target 40%), `p-6` + `gap 12` + `breakAfter`
- **Typografia:** body 11-12 px (14 pt print), LH 1.6, tracking 0.3, left-align, infant font — `tokens.typo`
- **Kontrast:** ≥4.5:1 text / 3:1 large/UI — `contrast-check.py` 4.87-7.88
- **Obraz:** `bytes>50KB` 1024, `whiteRatio>0.55`, `no text` — `manifest.json`
- **PDF:** 58-115k per karta, 84×3p pakiet ~9 MB, `build` PASS 10s, Vercel 1m
- **Czas sesji:** 8-10 min (str1 3 min słowa, str2 4 min ćwiczenia, str3 2 min mandala) — `InstructionCard time`

## 4. Governance

- **Audit co build:** `auditDesignSystem` + `imageAudit` + `pages.json` + `contrast-check.py` — warn >4 kolory, error words≠8, error `hasPersonalization===false`, error `whiteRatio<0.55`.
- **Manifest gate:** `bun run anim/src/batch.ts --dry --limit 20` przed PR — fail jeśli prompt bez `white background`.
- **AGENTS.md:** każdy nowy moduł = wpis w `Child DOX Index` + `layout.moduleBudget`.
- **Template:** 1 czysty szablon (header + name/date + font + marginesy + spacing) duplikowany — spójność w placówce. Rewizja 1×/rok.

---

## 5. Ryzyka i mitigacje

- **Ksero B&W:** kolor nie jedyny nośnik → test B&W + kształt+tekst P/S/K.
- **CMYK drift:** neon poza gamutem → proof fizyczny + round-trip RGB→CMYK→RGB re-check.
- **Laminat:** outer 12 mm safe, inaczej treść pod folią odcięta.
- **Gutter:** nigdy tekst/obraz przez środek — inner margin > outer.
- **Lockfile bun v2 vs Vercel bun 1.3:** `bun.lock` ignorowany (warn) — `install` fallback, nie blokuje build.
